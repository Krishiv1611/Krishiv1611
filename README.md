# 🧩 Featured Projects (Minimal & Clean)

### 🔹 **CareerPilot AI**  
An agentic, AI-powered job-search and resume-matching system using FastAPI, Streamlit, LangGraph, and SQLite.  
Includes: web search via SerpAPI, job analysis agents, resume parsing, and intelligent matching.

### 🔹 **Ridemate**  
A MERN-based ride-sharing platform for college students.  
Includes: ride creation, reservations, approvals, cancellations, co-passenger view, and community interactions.

### 🔹 **SummarizeYou**  
A YouTube RAG Chatbot built with **FastAPI backend + Chrome Extension frontend**.  
Fetches transcript → embeds → retrieves → answers queries in real-time using LLM-powered reasoning.
